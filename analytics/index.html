LinkedIn breaks out only the top metro areas, so 57% of the audience can be attributed to a country. The rest is not reported.

SQL
-- LinkedIn gives metro areas, not countries. The country
-- column is mapped on import, so the gap stays visible.
SELECT country, sum(percentage) AS pct
FROM audience
WHERE category = 'Location' AND country <> ''
GROUP BY 1 ORDER BY pct DESC;

       impressions, engagements,
       round(engagements * 100.0 / nullif(impressions,0), 2) AS rate
FROM top_posts
