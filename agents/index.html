11 agents in production shape

Each one does a real job — typed tools do the deterministic work, models only coordinate. Also served asagents.parquet.

  • API Test Generator ↗

    OpenAPI 3.x spec in, executable Postman collection out — pairwise parameter coverage, runs via Newman.

    eveAITestingOpenAPI

  • Diagram Generator ↗

    Plain-language description or sketch in, self-contained HTML architecture diagram out.

    eveAIDiagrams

  • GitHub PR Digest ↗

    Small multi-agent example: PR activity report across repos for a date range.

    eveAIGitHub

  • Job Matcher ↗

    Resume vs job postings, scored evidence-grounded JSON — governed rebuild of talent-align.

    eveAICareer

  • Job Pilot ↗

    Daily email of new matching jobs, reads Job Scout's public parquet snapshot.

    pythonAutomationCareerDocs ↗

  • Job Scout ↗

    Tracks ~95 companies' job postings with marimo + DuckDB, publishes a public parquet and a daily hiring-trends dashboard.

    pythonDataDuckDBCareerDocs ↗ Live ↗

    Tiny LangGraph StateGraph demo — no LLM, no network, no API key.

    langgraphAIEducation

  • LinkedIn Cover Generator ↗

    Article in, editorial LinkedIn cover image out — one reasoning pass plus one image generation.

    eveAIDesign

  • Privacy Classifier ↗

    Classifies PII/NPI and applicable compliance regimes in a document.

    eveAIPrivacy
